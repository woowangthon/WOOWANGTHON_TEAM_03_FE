# TK-44 · 2026-11-13 FE 후속 수정 검증

관련 업무: https://app.notion.com/p/3360a5c0c08041d39711567fb1dc2861

기준: main `8bff0b0` (PR #8의 이름·현재 비밀번호 입력 길이 제한 포함).

## 변경

- 보안 현황의 요청 5개 지표 문구·단위와 긴 제목의 글자 크기·줄바꿈을 조정했다. 탐지 수는 카드와 차트에서 `곳`으로 표시한다.
- 계정 팝업을 body 포털에 배치하고 최종 너비로 높이를 측정한다. 모바일 메뉴의 키보드 초점 관리에 포털도 포함한다.
- 셀렉트 선택지를 보이게 할 때 목록 내부만 스크롤한다. 선택 후 초점 복원도 페이지를 스크롤하지 않는다.
- 사용자 제공 사진을 로그인 소개 패널의 배경으로 추가했다. 사진 위 텍스트에는 어두운 그라데이션을 적용했다.
- 사용자 이력의 숨기기 문구를 삭제로 변경하고 삭제 동작·확인 버튼을 빨간색으로 구분했다. 기존 POST `/requests/{id}/hide/` 계약을 유지하므로 서버 원본과 관리자 감사 기록은 보관된다. 확인 문구에도 이를 명시한다.
- 승인 대기 화면과 삭제 함수에서 삭제를 차단한다. 외부 전송 거절 후 서버가 반환하는 `rejected` 상태에서 삭제할 수 있으며 `failed` 상태도 지원한다. FE가 서버 상태를 임의로 실패로 바꾸지 않는다.
- 정상 완료 답변의 더보기에는 삭제만 남긴다. 첨부 PDF 정보는 기본 표시하며 원본 보기·다운로드는 유지한다. 답변 누락·조회 실패 시의 복구용 상태 조회는 유지한다.

## 검증

- 단위/API 검사 36개 통과.
- 합성 API 브라우저 검사 109개: 최초 107개 통과 후 탐지 단위의 이전 기대값과 신규 승인 시험의 만료 시각을 수정했다. 영향받은 관리자·처리 흐름 50개를 재실행해 모두 통과했다.
- 체험 모드 브라우저 검사 17개 통과.
- real/real 프로덕션 빌드, Prettier 검사, `git diff --check` 통과.
- PC 1440px·모바일 390px의 로그인 사진 로딩, 계정 팝업 첫 열기·재열기 위치, 키보드 초점, 셀렉트 열기·키보드 선택 전후 페이지 스크롤 유지를 검증했다.
- 로그인·대시보드 캡처를 육안 확인했다. 기존 100·125·150·200% 유효 화면 폭 및 모바일 회귀 검사도 통과했다.
- 삭제 확인 취소·중복 클릭 방지·PDF URL 해제·권한 오류·응답 유실·화면 이동 후 목록 갱신, 프롬프트+PDF 승인 대기 중 삭제 미노출 및 거절 후 삭제를 검증했다.
