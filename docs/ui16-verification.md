## 실행 결과

| 명령                   | 결과                                                              |
| ---------------------- | ----------------------------------------------------------------- |
| `npm test`             | 단위/API 36개 통과                                                |
| `npm run test:e2e`     | 체험 UI 17개 통과                                                 |
| `npm run test:auth`    | 합성 API 브라우저 82개 통과                                       |
| `npm run build`        | real/real 성공. 기존 500kB 초과 JS 묶음 경고 유지(최종 약 526kB). |
| `npm run format:check` | 통과                                                              |
| `git diff --check`     | 통과                                                              |

브라우저 검사는 localhost에서 명시적 가상 API 응답을 사용한다. 실제 서버·실사용자 계정·외부 AI를 호출하지 않는다. 최초 실행 중 발견한 달력 초점, 접수 결과 복구 버튼, 상세 새로고침 후 스크롤 복원을 수정했다. 기존 승인 카운트다운 검사는 서버 만료 시각과 브라우저 가상 시계를 같은 기준으로 고정해 실행 속도 의존성을 제거했다.

## 화면 검토

로그인·보안 대시보드·열린 감사 필터 메뉴·사원 입력창을 PC 및 모바일 캡처로 확인했다. 화면 전체의 가로 넘침, 상세 버튼 두 줄, 메뉴가 화면 밖으로 나가지 않는지, 하단 계정 메뉴 접근, 입력·전송 버튼 접근을 검사했다.

1366×768 기준 확대에 대응하는 CSS 화면 크기는 1366×768(100%), 1093×614(125%), 911×512(150%), 683×384(200%)다. 추가로 390×844 모바일을 검사했다. 브라우저의 확대 설정 자체를 직접 변경한 시험은 아니다. 감사 표는 좁은 화면에서 표 내부 가로 스크롤을 제공한다.

## 제약과 후속 범위

- 부분 집계·집계 불가를 숨기면 확인 불가를 실제 0건으로 오인할 수 있어 이 상태는 유지했다.
- 사용자 단건 조회 API가 없어 변경 화면은 로그인 ID로 검색 후 정확한 사용자 ID를 대조한다. 직접 URL 진입은 기존 사용자 목록 API를 순회하므로 계정이 많으면 확인 시간이 늘 수 있다.
- 공개 배포·실제 서버 통합 시험·실제 AI 품질 검증은 수행하지 않았다.
- TK 전체 완료나 사람의 검토 완료를 판정하지 않는다.

## 추가 요청 2개 — 답변과 비밀번호 안내

- 완료 답변의 상세 제목·완료 배지·접수 번호·저장 안내·항상 보이던 요청문을 제거했다. 답변 자체의 Markdown 내용은 보존하고 복사·더보기 아이콘만 남겼다. 요청 정보·PDF·재조회·숨김은 더보기에서 수행한다. 답변 누락·권한 소멸·실패 시 복구 동작과 PDF URL 정리를 유지한다.
- 계정 발급·관리자 비밀번호 재설정·본인 비밀번호 변경에 공통 한 문장 안내를 넣었다. 10~30자, 각 문자 조합, 허용 문자 제한, 공통 비밀번호·계정 정보 유사성 제한을 굵은 검정 글자로 표시하고 해당 입력란의 접근성 설명에 연결했다. 서버 검증 정책은 변경하지 않았다.
- 신규 회귀 3개와 기존 검사까지 총 135개가 통과했다. 더보기 화면 경계, 복사 원문·실패, 누락 답변 복구, PDF·숨김·권한 소멸, 세 곳의 비밀번호 안내를 확인했다. 짧은 답변의 더보기 메뉴 잘림을 공통 위치 계산으로 수정했고, 감사 필터 변경 직후 이전 조건으로 페이지가 이동하는 경합을 막았다.
- 완료 답변 PC·모바일 및 비밀번호 재설정 캡처를 검토했다. 공개 서버 배포 결과는 별도 배포 기록으로 관리한다.
