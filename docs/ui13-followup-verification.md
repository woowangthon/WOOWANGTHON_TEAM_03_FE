# 후속 UI 13개 개선 검증

2026-11-12 · [TK-44](https://app.notion.com/p/3360a5c0c08041d39711567fb1dc2861)

이 문서는 앞선 16개 및 추가 2개 개선 이후의 사용자 요청을 반영한다. 기존 검증 이력은 `ui16-verification.md`에 보존한다.

| 요구 | 반영 결과 |
| --- | --- |
| 1 | 로그인 브랜드를 Mask Assistant로 변경. 로그인 이후 서비스명은 기존 이름 유지. |
| 2 | 로그인·계정·관리자 검색/필터·날짜·요청문·작성창을 M3 outlined 공통 필드로 통일. 라벨 노치·초점·입력값·자동완성·비밀번호 보기 및 아이콘 처리. |
| 3 | 아바타·이름·역할 전체가 하나의 계정 팝업 버튼. ID·이름·역할과 계정 설정·로그아웃 제공. 모바일 메뉴, 화면 경계, 바깥 클릭·Escape·초점 복원 지원. |
| 4 | 완료 답변 위에 보낸 질문을 항상 표시. 답변 제목·접수 번호 등 반복 안내는 다시 추가하지 않음. 첨부파일이 있을 때만 보기/숨기기 메뉴 제공. |
| 5 | 선택된 요청 아래의 새 요청 작성 버튼과 빈 작성 영역 제거. 왼쪽 새 요청 진입 유지. |
| 6 | 조회 조건 기본 숨김. 필터 아이콘으로 열고 닫으며, 입력 중인 조건은 닫아도 보존. 적용 조건·페이지 복원 유지. |
| 7 | 일별 그래프 처음 진입·기간 변경 시 오른쪽 최신 날짜로 이동. 같은 날짜 범위의 자동 갱신에서는 수동 스크롤 유지. |
| 8 | 감사 목록 상세 보기를 돋보기 아이콘으로 변경. 접근성 이름은 이용자 이름과 상세 보기 의미 유지. |
| 9 | 요청 이력·감사 목록·사용자 목록의 이전/다음 버튼을 화살표로 변경. 접근성 이름·페이지 번호·비활성 상태 유지. |
| 10 | 사용자 목록 작업 버튼을 돋보기 하나로 통합. 별도 계정 정보 화면에 로그인 ID·이름·UUID·상태와 이름 변경·비밀번호 재설정·비활성화 배치. 변경 화면→상세→목록 복귀, 직접 진입·새로고침·비활성 계정 조회 지원. |
| 11 | 본인 비밀번호 오류를 비밀번호 블록 위에 표시하고 필요한 만큼 스크롤. 이름 변경 오류와 분리. |
| 12 | 계정 발급·재설정·본인 변경의 규칙을 i 도움말에 네 항목으로 표시. 마우스·키보드·터치 지원, 굵은 글씨 및 화면 경계 대응. |
| 13 | 전송 시 접수→검사 시작을 한 번의 조작으로 수행. PDF만 접수한 경우 요청문 저장→검사 시작. 기존 자료 열기·새로고침·상태 조회는 시작하지 않음. 외부 전송의 승인/거절 유지. |

## 검증 범위

| 검사 | 결과 |
| --- | --- |
| `npm test` | 단위/API 36개 통과 |
| `npm run test:auth` 및 수정 항목 재검사 | 합성 API 브라우저 102개 통과 |
| `npm run test:e2e` | 체험 UI 17개 통과 |
| `npm run build` | real/real 빌드 성공, JS 약 531kB의 기존 크기 경고 유지 |
| `npm run format:check`, `git diff --check` | 통과 |

고유 검사 합계는 155개다. 전체 브라우저 실행에서 101개가 통과하고 기존 5분 대기 검사의 가상 시간/응답 경합 1개가 실패했다. 해당 검사는 응답이 화면에 반영된 뒤 시간을 진행하도록 수정하여 3회 연속 통과했다. 앞선 PDF 실패의 중복 오류 안내와 답변 메뉴의 무동작 항목도 수정 후 해당 접수·처리 검사 및 전체 실행에서 확인했다.

- 정상 접수와 PDF 선접수, Enter/IME, 응답 유실·추출 실패·불확실한 접수 복구, 중복 전송 방지.
- 시작 대기 중 계정 화면으로 이동하거나 새 이력을 열어도 최신 상태·오류와 목록 갱신 유지.
- 비밀번호 오류 위치·빈 필드 기본 검증·도움말 3곳, 계정 팝업 키보드·모바일 조작.
- 관리자 필터 접기/열기·조건 보존, 30일 차트 최신 위치와 자동 갱신, 사용자 상세·편집·비활성화·검색 조건 복귀.
- 1366×768 기준 100/125/150/200%에 대응하는 유효 CSS 화면 폭과 390px 모바일 배치. 브라우저 확대 설정 자체나 실제 휴대폰 시험은 아님.
- PC·모바일 로그인, 작성창, 답변, 비밀번호 도움말, 계정 팝업, 관리자 필터 및 사용자 상세 캡처 검토.

## 한계

- 브라우저 검사는 localhost의 명시적인 합성 API 응답과 체험 모드다. 이번 변경에서 실제 계정 변경·외부 AI 호출·공개 서버 배포는 수행하지 않았다.
- 사용자 단건 조회 API가 없으므로 상세 직접 진입 시 기존 사용자 목록 API에서 정확한 UUID를 찾아 확인한다.
- 비밀번호 규칙은 서버 정책을 설명하며 서버 검증을 변경하지 않았다. 서버가 제공하지 않는 허용 특수문자 목록은 임의 생성하지 않는다.
- 부분 집계·집계 불가는 실제 0건과 구분하기 위해 유지한다. 기존 단일 JS 묶음 500kB 경고가 남는다.
- TK 전체 완료나 사람의 검토 완료로 처리하지 않는다.
